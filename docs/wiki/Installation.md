# Installazione

1. Scarica una release dal repository ufficiale.
2. Verifica hash e provenienza dell'archivio.
3. Estrai in una cartella locale non temporanea.
4. Avvia `WinHubX.exe` e concedi elevazione solo alle operazioni che la richiedono.

Per compilare dal sorgente consulta [CONTRIBUTING.md](../../CONTRIBUTING.md). Il branch stabile usa .NET 10; il branch Net 11 è sperimentale.
