# Risoluzione problemi

## L'app non si avvia

Verifica Windows x64, il Desktop Runtime richiesto e l'integrità del pacchetto. Avvia da una cartella locale e controlla i log senza pubblicare dati sensibili.

## Una funzione richiede riavvio

Alcune modifiche di Windows sono applicate solo al riavvio di un servizio o del sistema. Salva il lavoro e riavvia manualmente quando l'app lo indica.

## Download non riuscito

Controlla rete, proxy, data/ora di sistema e disponibilità della fonte ufficiale HTTPS. Non sostituire l'URL con mirror sconosciuti.
